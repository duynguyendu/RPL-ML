\subsection{Permutation Importance}
\cite{altmannPermutationImportanceCorrected2010}

model inspection technique that measures the contribution of each
feature to a fitted model’s statistical performance on a given tabular dataset
- Useful for non-linear model.

The baseline score of the model $s$ on a certain dataset.
For each feature in the dataset, the algorithm permuate the value of
that feature with other rows to create a corrupted version of the
dataset and run the model through that $K$ times.
The feature importance is calculated as

\begin{equation}
    i_j = s - \frac{1}{K} \sum_{k=1}^{K} s_{k,j}
\end{equation}

\subsection{SHAP}
SHapley Additive exPlanations (SHAP) is technique that measures the
average magnitude of a feature's contribution to a model's
predictions across a dataset based on cooperative game theory.
Measure how each feature influence the outcome of the model.

Explaining a generalized additive regression model

We use Tree SHAP is a fast and exact method to estimate SHAP values

    \phi_i = \sum_{S \subseteq F \setminus \{i\}} \frac{|S|!\,(|F| -

    \{i\}}\right) - f_S\!\left(x_S\right) \right].
\end{equation}
