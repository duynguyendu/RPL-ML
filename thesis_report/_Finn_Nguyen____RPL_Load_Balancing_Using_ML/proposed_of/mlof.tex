\section{Proposed Objective Function MLOF}
Most existing OFs rely on a few immediate routing metrics, which make them
selects the neighbour with the best link
quality without considering the performance of the route as a whole.
Among the ML-based OFs reviewed in Section~\ref{sec:related-work},
most are based on reinforcement learning, and the only supervised
approach predicts the probability that a single packet is
transmitted successfully, which does not capture the longer-term
behaviour of the link. Thus we propose MLOF, which uses a regression
model embedded into the OF to predict the PDR that a node would
achieve through a candidate parent. We include several load related
metrics alongside with link and node metrics so the model can learn
to avoid the congested paths as discussed in Section~\ref{sec:data-collection}.

Overall, we compute the $\mathit{Rank\_Increase}$ as
\begin{equation}
    \mathit{Rank\_Increase} = \alpha \cdot PDR
    + (1 - \alpha) \cdot \mathit{ETX},
\end{equation}
ETX is retained as a safeguard against the predictions of
the model, which would otherwise lead to an unstable DODAG and degrade
the network performance. To further stabilise the topology, we
include rank hysteresis of 64 and a time hysteresi of 10 minutes.
