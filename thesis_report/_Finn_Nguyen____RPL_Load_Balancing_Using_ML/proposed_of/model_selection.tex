\subsubsection{K-Nearest Neighbor Regression (KNNR)}
% TODO: what is nonparametric
KNNR is a common nonparametric supervised learning model
\cite{KNNRSONG201726}. It works by
mapping the unseen point with the k-nearest neightbours to predict
the value that the new point should that, usually the average of the
k-neighbours
. The principle behind this
model is that points that are similar to each other would have the
similar property.
The prediction can include inverse weight based on the distance from
the neighbours
Generally, the closeness between points is measured by the Euclidean
or Mahalanobis distance between them,
% TODO: list some other distance as well
% TODO: insert equation for Euclid distance
The choice of k depends on the application and is usually the subject
of hyperparameter searching.
Since KNNR relies on the distance between features, normalisation and
scaling can often improve the accuracy of the model.

KNNR has the advantage of not needing to train at all, instead the
model remembers the training data, which would be used for the
interference. This also means that appending new training data to the
model is very simple as the new observations can be appended.
However, this is also one of the weakness of KNNR, it cannot work
effciently with large datasets and in high dimensional space, it also
quite sensitive to noise, outliers and missing values.

Despite KNNR is relatively simple, KNNR does not meet our requirement
of being lightweight and is quite computational heavy interference as
it has to perform O(n) calculation, evaluating each point in the
training dataset.

\subsubsection{Gaussian Process Regression (GPR)}
GPR is a probabilistic supervised machine learning model. It makes
prediction by incorperating the knowledge from the kernel and
provides the uncertainty measure over its prediction
\cite{wangIntuitiveTutorialGaussian2023}.

Use multivariate Gaussian distribution
\begin{equation}
    P_X(x) = \frac{1}{\sqrt{2\pi}\,\sigma} \exp\left( -\frac{(x -
    \mu)^2}{2\sigma^2} \right).
\end{equation}

The Gaussian Process is the process that fits each feature in the training dataset to a Gaussian Distribution and then join them together to create a probabilistic prediction functions.
In regression model, the output is mean and variance with the ... is the predicted value.

The kernel, or covariance function, plays a pivotal role in this
smoothing process, encapsulating our prior knowledge about the
functions we aim to model
